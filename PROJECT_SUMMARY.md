# AI Job Search Automation Dashboard - Project Summary

**Portfolio role target:** Junior AI Engineer, Junior ML Engineer, AI Operations Analyst, Data Analyst, Prompt Evaluator, LLM Evaluator, Workforce Analytics.

**Problem:** Recruiters need to see quickly that Juan can connect business operations, data, and AI-adjacent evaluation work in a practical way.

**Solution:** Synthetic job-application pipeline dashboard with fit score, status, platform, response rate, and follow-up tracking.

**Data policy:** 100% synthetic sample data. No employer records, student records, client records, emails, credentials, medical data, family data, or real application data.

**What to inspect first:** `README.md`, `data/sample_synthetic_data.csv`, and the main script in `src/`.

**Primary signal:** Juan can model a real operational workflow as a data product while keeping actual job-search records private.
